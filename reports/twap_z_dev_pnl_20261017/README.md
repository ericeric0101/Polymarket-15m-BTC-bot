# TWAP-z 開發樣本損益分析（2026-10-17，附錄 A1.3 解盲後）

**性質：** 探索性。依附錄 A1.3，這些市場不能再作為確認性證據。

**資料：**
- v2（BTC 15m）：2026-10-15T01:00Z 起；v3（其他 7 個串流）：2026-10-16T03:00Z 起；都只算 T_U（2026-10-17T03:30Z）之前開盤的市場。
- 盤口採因果取值（附錄 A1.1）；結果用官方 Gamma 標籤。
- 規則完全照凍結版本：ZC、T−55…T−5、`0.10 ≤ mid ≤ 0.90`、`|z| ≥ 2`、每市場第一次符合、以 ask 買進、扣 taker fee。

**資料覆蓋：** 1,352 個市場中，只有 879 個在 11 個 checkpoint 都有盤口。原因是 10/16–10/17 的盤口遺失（見 data_gaps.md），遺失只和「每小時的第幾分鐘」有關，和結果無關，所以只是樣本變小、不造成偏誤。

各串流的樣本都只有 1–8 筆，沒有統計意義，只列出供參考：BTC 15m −0.14（7 筆）、BTC 5m −0.16（7）、ETH 5m −0.04（6）、SOL 5m +0.17（5）、XRP 5m +0.14（8 筆全勝）。

**判讀：**
- 勝率 81% 和平均買價 0.80 幾乎相同，代表**市場價格大致已經反映了最後一分鐘的結算機制**。這和 Entry V3 的情況一樣。
- 平均每股淨損益約為 0，但信賴區間約 ±0.13：既無法證明有優勢，也無法排除每股約 +0.1 的優勢。
- 先前 10/3–10/6 開發資料的估計是每市場約 +0.11（13 筆），**這次沒有重現**。
- 5m 偏正、15m 偏負；|z| 3–5 有 4 筆全勝。這些都是看完結果才切出來的分組，**不得**據此修改規則。若要測試，必須另寫事前登記，並使用 T_U 之後的資料。

## 定局單（plan_v2 §7，描述性）

**結果：** 658 個市場中，結算價完全確定的時間點是 T−1（417 個）或 T−2（241 個）。在那一刻，會贏的那一側**只有 1 個市場還有 ask**。

**結論：** 市場在最後 1–2 秒已經完全定價，沒有任何東西可以買。**定局單不可行。**
